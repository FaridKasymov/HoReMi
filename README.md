# HoReMi

HoReMi — международная система для гостиниц, которая превращает телевизоры в фирменные информационные экраны с музыкой.

На экране можно показывать логотип и название отеля, адрес на двух языках, время, дату, погоду и фоновые изображения. Телевизоры подключаются по одноразовому коду, а сотрудники управляют радиостанцией через Telegram-бота.

## Что уже работает

- полноэкранная заставка для телевизора;
- логотип, название, адрес, дата, время и погода на русском и английском;
- фоновое слайд-шоу и анимация заставки;
- подключение нового ТВ по одноразовому коду через Telegram-бота;
- переключение радиостанций через бота;
- единая внутренняя админка для отелей, телевизоров, станций и заявок;
- PIN-вход в админку;
- международный лендинг с формой заявки на демонстрацию;
- семь стартовых радиостанций.

## Локальный запуск

1. Скопируйте `.env.example` в `.env`.
2. Заполните `BOT_TOKEN` и `ADMIN_ID`.
3. Задайте свой `ADMIN_PIN`.
4. Запустите проект:

```bash
docker compose up -d --build
```

После запуска:

- сайт: `http://localhost:8000/`;
- демонстрация заставки: `http://localhost:8000/demo`;
- админка: `http://localhost:8000/admin`.

Чтобы открыть сайт с другого устройства в домашней сети, используйте локальный IP компьютера, например `http://192.168.x.x:8000/`.

## Админка

Админка предназначена для владельца или администратора HoReMi. Клиентам отдельная панель не предоставляется: они используют Telegram-бота.

В админке доступны:

- список отелей и их настройки;
- назначение радиостанции отелю;
- каталог и редактирование радиостанций;
- список подключённых телевизоров;
- привязка и отвязка экранов;
- заявки с лендинга.

PIN задаётся переменной `ADMIN_PIN` в `.env`. После входа сервер выдаёт временную cookie-сессию. Не добавляйте `.env` в Git и используйте отдельный сложный PIN для размещённой версии.

## Подключение телевизора

1. Откройте на телевизоре ссылку `/public/index.html` или `/demo`.
2. На экране появится шестизначный одноразовый код.
3. Отправьте код Telegram-боту с аккаунта, который разрешён для нужного отеля.
4. После подтверждения заставка и станция загрузятся автоматически.

## Структура

- `main.py` — FastAPI-приложение и основные маршруты;
- `api/endpoints.py` — API телевизоров, админки и заявок;
- `db/models.py` — модели базы данных;
- `db/database.py` — подключение, миграции и стартовые станции;
- `bot.py` — Telegram-бот;
- `public/index.html` — экран телевизора;
- `public/admin.html` — внутренняя админка;
- `public/landing.html` — сайт HoReMi;
- `public/hotels/<slug>/` — логотип и медиа конкретного отеля.

## План развития

- демонстрационные экраны на лендинге для ресторанов и кафе;
- отдельные визуальные сценарии для гостиниц, ресторанов и кафе;
- расширенные настройки заставок и фоновых коллекций;
- безопасное публичное размещение с HTTPS и резервным копированием базы;
- более гибкие роли для команды владельца проекта.

## Важно перед продажей

Для локальной сети текущего запуска достаточно. Перед публичным коммерческим размещением нужно включить HTTPS, вынести секреты в защищённое хранилище, настроить резервные копии базы и заменить локальный PIN.
